## Upload (@clipmeapp)
1. **16:9 video:** paste the title, description and tags from `youtube-description.txt`. Set `thumbnail.jpg`. Upload `captions.srt` under Subtitles → English → "With timing". Category: Science & Technology. Not made for kids.
2. **Short:** upload `short.mp4` (vertical and under 60s, so YouTube files it as a Short) with `short-description.txt`. The same file works on TikTok and Reels; there, point viewers to the link in bio.
3. Put the 16:9 videos in one playlist, and link each Short to its long video with the "Related video" field.
4. Pin a comment with the page link on each 16:9 video.
5. After uploading, paste the real YouTube IDs into `demo-videos-snippet.js` and add the wired entries to `clipme-landing/src/lib/demo-videos.js`.

## Hands-off upload (API)
`upload_to_youtube.py` uploads every video and Short in order: title, description, tags, thumbnail, captions and one playlist. It reads `YT_CLIENT_ID`, `YT_CLIENT_SECRET` and `YT_REFRESH_TOKEN` from the environment, and saves progress to `uploaded.json` so a rerun resumes. Run `python3 upload_to_youtube.py --dry-run` first. Until Google approves the API project's audit, YouTube locks API uploads as Private.
